# LinkedIn Post Patterns

## 포맷 길이

| 유형 | 길이 | 용도 |
|------|------|------|
| Short | ≤300자 | 공지, 퀵 인사이트, 채용 링크 |
| Mid | 300–1,300자 | 일반 인사이트, 사례 공유, 업데이트 |
| Long | 1,300–3,000자 | 씬 리더십, 케이스 스터디, 회고 |

LinkedIn 본문 상한: **3,000자**. 해시태그 권장: **3–5개**.

## 훅 패턴 (첫 2줄에 반드시)

모바일 "see more" 이전 약 210자가 분수령.

- **Counter-intuitive**: "우리는 £X을 썼다. 그리고 배운 것은 대부분의 팀이 이미 안다는 점이다."
- **Number-led**: "3주. 12명 인터뷰. 결론 하나."
- **Confession**: "처음 6개월, 내가 틀렸다."
- **Question**: "왜 우리 SDR 팀은 매주 같은 실수를 반복했을까?"
- **Scene-setting**: "어제 고객 한 명이 이메일을 보냈다. 내용은 단 한 줄."

금지: "In today's fast-paced world…", "I'm thrilled to announce…" 류 AI/클리셰 오프닝.

## 구조 템플릿

### 1) Insight (씬 리더십)
```
[Hook 2줄]

[맥락 1단락]

[핵심 주장 1문장]

[근거·예시 3개 — 불릿 또는 짧은 단락]

[반론 고려 1단락]

[실행 가능한 결론 1문장]

[CTA: 질문 or 리소스 링크]

#해시태그 3–5
```

### 2) Announcement (발표)
```
[Hook: 무엇이 바뀌었는가]

[누가·언제·왜]

[수치/증거]

[독자에게 의미]

[CTA: 신청·지원·DM]

#해시태그
```

### 3) Case Study (사례)
```
[Hook: 숫자 or 결과]

Before: [상황]
Change: [한 일]
After: [결과]

[핵심 교훈 1–3개]

[CTA]

#해시태그
```

### 4) Hiring (채용)
```
[Hook: 팀/미션]

Role: [직무·레벨]
You: [이상적 후보]
Why: [이 기회가 특별한 이유]
Stack/Work: [기술·업무]

[지원 링크 + DM 안내]

#해시태그
```

## CTA 선택

- **저장**: "이 글을 저장하세요." (리치한 리소스형)
- **댓글**: "동의하는지, 반박하는지 댓글로 남겨주세요."
- **DM**: "관심 있으면 DM 주세요."
- **링크**: "자세한 내용은 첫 댓글의 링크."
- **채용**: "지원 링크는 프로필 상단에."

## 서식 규칙

- 모바일 가독성: 한 단락 **3–4줄** 이내.
- 이모지: 단락 구분자로 **0–3개**까지. 장식 금지.
- 대문자 강조(SHOUTING) 금지.
- 따옴표 인용은 1개만.
- 해시태그는 본문 마지막에 모아서.
- 첫 댓글에 링크를 두는 관습 존중(본문 링크는 도달 제한 이슈가 있다고 알려짐).

## 평가자가 감지할 AI 슬롭 체크리스트

반드시 제거:
- "In today's fast-paced world"
- "Game-changer", "Synergy", "Leverage" 남용
- "- " 문두 불릿을 5개 이상 연속
- 모든 문장이 비슷한 길이
- "1. Do X. 2. Do Y. 3. Do Z." 류 일반화 리스트
- 과한 이모지 불릿 (🚀✅💡…)
- 따옴표로 감싼 자기 선언
